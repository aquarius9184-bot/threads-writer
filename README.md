# 스레드 반응글 작성기

원하는 반응(조회수·좋아요·답글·리포스트·저장·팔로우·DB 수집)을 고르면, 조회수 3만 이상 스레드 글을 분석해서 나온 12가지 구조로 본문(1/2)과 답글(2/2)을 써주는 웹 페이지예요.

## 쓰는 법

1. 계정 분야, 타깃 독자, 말투, 이번 글 주제를 적어요.
2. 실제 경험·수치를 적으면 그 숫자만 사실로 써요. 없는 성과는 `[대괄호]`로 비워둬요.
3. 원하는 반응을 고르면 추천 구조가 선택돼요. 직접 골라도 돼요.
4. **글 쓰기**를 눌러요.

## 글 생성 방식

- **API 키가 있을 때:** 페이지의 "API 키로 바로 생성"에 Anthropic API 키를 넣으면 바로 써줘요. 키는 그 브라우저(localStorage)에만 저장되고 Anthropic API로만 보내져요. 사용료는 키 주인에게 청구돼요.
- **API 키가 없을 때:** 완성된 프롬프트가 나와요. 복사해서 Claude나 ChatGPT 채팅에 붙여넣으면 돼요.

공용 컴퓨터에서는 다 쓴 뒤 "키 지우기"를 눌러주세요.

## 12가지 구조

| 원하는 반응 | 추천 구조 |
|---|---|
| 조회수 | 공감 고민·후기 고백, A vs B 대비 |
| 좋아요 | A vs B 대비, 짧은 숫자 리스트 |
| 답글 | 열린 질문 "~있어? 나는", 친구 모집·자기소개 |
| 리포스트 | 충격 단언·변화 선언, 짧은 숫자 리스트 |
| 공유·저장 | 하지 마세요 → 대신 이렇게, 무료 공개 + 금액 앵커 |
| 팔로우·신뢰 | 권위 + 방법 공개, 친구 모집·자기소개 |
| DB 수집 | 성과 + 댓글 리드마그넷 |

그 밖에 업계 폭로·민낯, 역설·금지 훅도 있어요.

파일 하나(`index.html`)로 된 정적 페이지라 빌드할 게 없어요.
