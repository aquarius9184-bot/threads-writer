# 스레드 반응글 작성기

원하는 반응(조회수·좋아요·답글·리포스트·저장·팔로우·DB 수집)을 고르면, 조회수 3만 이상 스레드 글을 분석해서 나온 12가지 구조로 본문(1/2)과 답글(2/2)을 써주는 웹 페이지예요.

## 쓰는 법

1. 계정 분야, 타깃 독자, 말투, 이번 글 주제를 적어요.
2. 실제 경험·수치를 적으면 그 숫자만 사실로 써요. 없는 성과는 `[대괄호]`로 비워둬요.
3. 원하는 반응을 고르면 추천 구조가 선택돼요. 직접 골라도 돼요.
4. **글 쓰기**를 눌러요.

## 회원과 승인

- 이메일과 비밀번호로 회원가입 → 관리자가 승인하면 사용할 수 있어요. (메일 인증 없음)
- 승인된 회원은 하루 5회(한국 시간 자정에 초기화)까지 쓸 수 있어요. 관리자 화면에서 사람별로 바꿀 수 있어요.
- 관리자 화면: `admin.html`

## 구조

- 화면: GitHub Pages (`index.html`, `admin.html`)
- 회원·승인·사용 횟수: Supabase Auth + Postgres (`supabase/migrations`)
- AI 호출: Supabase Edge Function `generate` (`supabase/functions/generate`). API 키는 Supabase secret `GEMINI_API_KEY`(우선) 또는 `ANTHROPIC_API_KEY`에만 있고 브라우저로 보내지지 않아요.

## 17가지 구조 (v4.01)

| 원하는 반응 | 볼 지표 | 추천 구조 |
|---|---|---|
| 조회수 | 조회수 | 구체적 관찰·예상 밖 장면, 도구로 생활 문제 끝내기, 답하기 쉬운 경험 질문 |
| 답글·대화 | 답글률 | 답하기 쉬운 경험 질문, 도움 요청, 숫자가 있는 현실 고민 |
| 공감·좋아요 | 좋아요율 | 과정 기록·작은 변화, 경력·작업 범위 자기소개, 진짜 사람의 일상 |
| 공유·확산 | 공유·리포스트율 | 실무 자료 공유, 도구로 생활 문제 끝내기, 시작 행동이 보이는 단계 |
| 신뢰·팔로우 | 좋아요율·프로필 방문 | 경력·작업 범위 자기소개, 해결 과정·전후 비교, 현업 경력 + 단계별 방법 |
| 문의·신청 | 문의·신청·클릭 | 해결 과정·전후 비교, 경력·작업 범위 자기소개, 자료 신청 받기 |

그 밖에 선택지 판단 질문, 가치관이 갈리는 이야기, A vs B 대비, 업계 현장 일기도 있어요. 구조는 한 번에 최대 3개까지 고를 수 있어요. 분야(마케팅·자기계발·인스타그램·스레드·AI·일상·가게)를 고르면 분야별 전개와 첫 문장 틀을 함께 반영해요. 원하는 반응마다 마무리 방식과 주의할 점도 프롬프트에 들어가요.

바뀐 내용은 [CHANGELOG.md](CHANGELOG.md)에 있어요.

파일 하나(`index.html`)로 된 정적 페이지라 빌드할 게 없어요.
